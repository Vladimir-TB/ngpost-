# ngPost+ 5.1.2

Windows x64 release with improvements to themes, large posting batches and session controls. The installer and portable ZIP contain the same application. **The app and installer are unsigned.**

## Improvements

- Choose a theme colour in Preferences: the entire light or dark interface follows it, including dialogs. The choice persists after restart.
- **Start all sessions** queues ready sessions in tab order, with one upload job running at a time.
- Copy the NZB filename, archive name and session password using the buttons under **Show advanced**, including after posting.
- Large folder scans and session generation show progress, support cancellation and keep the interface responsive.
- Help now includes these improvements and fixes in English and Dutch.
- Clear upload responsibility notice, original author credits, bundled component licenses and corresponding source downloads.

## Fixes

- Reduced freezes during folder processing, between queued jobs and while stopping uploads or compression tools.
- Prevented duplicate sessions and repeated queueing; retained the correct session passwords and completed NZB data.
- Added non-blocking NZB conflict handling: skip, overwrite, unique name or cancel, with apply-to-all support.
- Installer defaults to English and also offers Dutch. Upgrades retain the previous language, installation folder, portable mode and configuration.

## Install or update

- **Installer:** close ngPost+ and run `ngPost-setup-v5.1.2-UNSIGNED.exe`. Installing for the same Windows user in the existing installation folder updates the previous version. No automatic background updater is included.
- **Portable:** extract all of `ngPost-portable-v5.1.2-UNSIGNED.zip`. When updating an existing portable folder, close the app and retain your `ngPost.conf`; the download contains no personal configuration. If Windows reports missing VCRUNTIME/MSVCP DLLs, install the included Microsoft redistributable.
- Windows may warn about the unsigned app/installer. SHA-256 checksums are listed below.
- RAR is a separate licensed tool. Bundling does not grant an unlimited RAR usage license; see `notices/RAR-EULA-en.html` for its trial and licensing terms.

## Nederlands

De hele UI kleurt mee met je gekozen themakleur. **Alle sessies starten** verwerkt voorbereide sessies op volgorde; **Kopieer** staat naast de metadata onder **Geavanceerd tonen**. Grote mapbatches blijven beter reageren en zijn te annuleren. Vastlopers, dubbele sessies, wachtwoord-/NZB-gegevens en installer-upgrades zijn verbeterd. Het volledige overzicht staat in **Help → Nieuw in 5.1.2**.

Sluit de app vóór bijwerken. Gebruik de installer bij een bestaande installatie; pak bij portable gebruik de hele ZIP uit en behoud `ngPost.conf`. App en installer zijn niet digitaal ondertekend. Upload alleen materiaal waarvoor je verspreidingsrechten hebt.

## Validation and source

Release build, Dutch/English Help and theme smoke checks, local NNTP queue tests, folder batches up to 500 entries, and isolated installer/portable upgrade checks. Real-provider posting and a clean Windows machine were not part of these automated checks.
